How I work

Principles I bring to every CRM project

  1. Start with the process, not the tool

    I run conversations with the people doing the work, map the process end to end, and only then decide what to configure.

  2. Clean data comes first

    Validation rules, duplicate checks and careful imports. A dashboard is only as good as the records behind it.

  3. Automate the repetitive parts

    Flows for onboarding, KYC and pre-sales take manual steps off people's desks so they can focus on customers.

  4. Adoption is the finish line

    A feature isn't done when it's deployed. It's done when people use it, so I test, train and gather feedback.

  5. Document it so it lasts

    Clear documentation and user guides mean the system doesn't depend on one person to keep running.
